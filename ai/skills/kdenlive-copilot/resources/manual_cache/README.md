# Manual cache

Full mirror of the Kdenlive manual, converted from the official
`KdenliveManual.epub` (linked from docs.kdenlive.org), one file per page,
mirroring the site's own path structure (e.g. `effects_and_filters/audio.md`
for `.../effects_and_filters/audio.html`).

Empty until `../../scripts/fetch_manual.py` runs — the
kdenlive-copilot skill runs it on first need, see SKILL.md "Manual cache"
section. Not hand-maintained; re-run the script to refresh rather than
editing files in place.
