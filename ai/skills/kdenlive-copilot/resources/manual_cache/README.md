# Manual cache

Fetched pages from docs.kdenlive.org, one file per page, named after the
page's URL slug (e.g. `audio.md` for `.../effects_and_filters/audio.html`).

Populated lazily by the kdenlive-copilot skill on first query that needs a
given page — see SKILL.md "Manual cache" section. Not hand-maintained;
refetch and overwrite rather than editing in place.
